# Как выпустить версию (чек-лист)

Делай по порядку. Когда пройдёшь вручную 2-3 раза, эти шаги автоматизируем (GitHub Actions).

## Перед каждым публичным релизом: сверь код с политикой конфиденциальности
Политика на сайте описывает то, что приложение делает. Если код изменился, а текст нет, политика становится неправдой.
- [ ] В AndroidManifest.xml только разрешение INTERNET (политика обещает "единственное разрешение").
- [ ] В коде нет новых серверов, аналитики, рекламы, отправки отчётов (политика обещает, что их нет).
- [ ] Добавил хранение новых данных или новые сетевые запросы? Сначала поправь privacy.html, повысь версию документа и дату.
- [ ] minSdk в build.gradle.kts совпадает со строкой "Android 7.0 и новее" на сайте (24 = Android 7.0).
- [ ] Вход и оценки работают с включённой блокировкой YouTube и внешних ресурсов (HostPolicy). Если что-то сломалось, пришли лог.

## Выпуск
1. Всё слито в main, тесты зелёные (`./gradlew test`).
2. В build.gradle.kts подними vMajor/vMinor/vPatch.
   - исправил ошибку: vPatch + 1
   - добавил функцию: vMinor + 1, vPatch = 0
3. Коммит и метка:
   ```
   git add -A
   git commit -m "Версия 0.2.0"
   git tag -a v0.2.0 -m "Что нового"
   git push && git push --tags
   ```
4. Сборка: `./gradlew assembleRelease`
   Файл: `app/build/outputs/apk/release/app-release.apk`. Переименуй его в `WatchYourGrade.apk`
   (имя одинаковое у ВСЕХ версий: на нём держится ссылка "последняя версия" на сайте).
5. Проверь подпись (apksigner лежит в Android/Sdk/build-tools/<версия>/):
   `apksigner verify --print-certs WatchYourGrade.apk`
   Отпечаток сертификата (SHA-256) должен быть ВСЕГДА одним и тем же. Если изменился, обновления не встанут.
6. GitHub (репозиторий сайта grades-site) → Releases → Draft a new release: тег `v0.2.0`, прикрепи `WatchYourGrade.apk`.
7. Сделай latest.json:
   ```
   python tools/make_latest_json.py WatchYourGrade.apk --version-code 200 --version-name 0.2.0 \
     --base-url https://github.com/ИМЯ/grades-site/releases/download/v0.2.0/ \
     --notes "Что нового" > latest.json
   ```
   Положи latest.json в корень репозитория сайта, закоммить и запушь.
8. Поставь APK поверх старой версии на своём телефоне: данные и оценки должны остаться.
   Затем на телефоне со СТАРОЙ версией дождись баннера "Доступна версия" (или проверь на втором телефоне).

## Ключ подписи
- Файл .jks и пароли храни В ДВУХ местах вне проекта (менеджер паролей, зашифрованная флешка).
- Потеряешь ключ: обновления поверх не поставятся, пользователям придётся удалить приложение,
  а значит потерять локальную историю оценок. Утёк ключ: можно выпустить подделку под твоим именем.
