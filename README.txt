ЧТО ИЗМЕНИЛОСЬ
  «Аналитика» -> «Цель»: два переключателя.
   - Предмет / Общий средний. Для общего цель считается по среднему из средних по предметам (как в «Обзоре»:
     каждый предмет весит одинаково, сколько бы в нём ни было оценок).
   - Семестр / Год. Переключатель виден, только когда оценки есть минимум в двух семестрах.
     «Год» = все оценки предмета из обоих семестров вместе, средний по всей куче. Это написано в примечании.
     Работает и для предмета, и для общего среднего. Цели «за год» и «за семестр» хранятся отдельно.
  Для общего среднего два блока вариантов:
   - «Подтягивать все предметы поровну»: по N десяток / девяток / восьмёрок / семёрок в КАЖДОМ предмете и сколько
     это всего оценок. Это самый реалистичный сценарий.
   - «Только в одном предмете»: сколько оценок нужно, если все новые только в нём. Предметы отсортированы:
     кто вытянет быстрее всех, тот первый. Если предмету одному не под силу даже десятки, он вынесен
     в последнюю строку («одним этим предметом цель не достичь»).
  Пороги «реально / сложно» для общего: до 2 десяток в каждом предмете реально, до 4 сложно, дальше нет.
  Они условные, лежат в OverallPlanner.EVEN_EASY_MAX и EVEN_HARD_MAX.
  Над расчётом сразу видно «Сейчас: 8.43 · 9 предметов» (число красится по шкале оценок).
