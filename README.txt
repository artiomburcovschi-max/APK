ПОЧЕМУ ОБНОВЛЕНИЕ НЕ ПОЯВЛЯЛОСЬ (4 причины в старом коде)
  1. Время проверки сохранялось ДО запроса. Любой сбой (нет сети на секунду, GitHub Pages ответил ошибкой,
     таймаут) всё равно считался проверкой, и следующая была только через сутки.
  2. Интервал в сутки даже после успешной проверки: выложил версию через час после проверки, и приложение
     не узнает о ней до завтра.
  3. Проверка была только при СОЗДАНИИ экрана. Если приложение живёт в списке недавних днями, оно не
     проверяло ни разу. Переустановка = новый процесс и пустая память, поэтому «помогала».
  4. Любая неполадка (ссылка не из доверенного репозитория, битый latest.json, ответ 404) молча давала
     «обновления нет», узнать причину было нельзя.

ЧТО СДЕЛАНО
  - Два времени вместо одного: успеха (после него следующая проверка через 6 часов) и попытки
    (после неудачной повтор через 10 минут). Сбой больше не блокирует на сутки.
  - Проверка при КАЖДОМ выходе приложения на экран (onStart), а не только при создании.
  - Запрос идёт с параметром ?t=время и заголовком no-cache: CDN GitHub Pages не отдаёт вчерашний файл.
  - «О приложении» -> «Проверить обновления»: спрашивает сервер сразу и говорит результат словами:
    «Доступна версия X» (+ кнопка «Скачать»), «У тебя последняя версия», или причину сбоя:
    нет интернета / таймаут / код ответа сервера / latest.json не разобрать / ссылка не из доверенного репозитория.
    Там же строки: что установлено, когда была последняя успешная проверка, что на сервере.
  - Ручная проверка снимает прежнее «Не сейчас» по этой версии (человек сам спросил).
  - Разбор latest.json терпит невидимый BOM и пробелы в начале (бывает, если файл сохранён Блокнотом/PowerShell).

ЧЕК-ЛИСТ ПРОВЕРКИ
  [ ] Обычный запуск, баннер и вход работают как раньше
  [ ] «О приложении»: видны строки «Установлена…», «Проверка ещё не выполнялась» (или время) и кнопка
  [ ] Нажми «Проверить обновления» на этой версии: либо «У тебя последняя версия (на сервере X)»,

      с UpdateConfig.TRUSTED_APK_PREFIX (сейчас .../artiomburcovschi-max/APK/releases/download/)
  [ ] Режим полёта + «Проверить»: «нет интернета…», кнопка снова активна; выключи режим, нажми ещё раз: проверка проходит
  [ ] Главный тест: поставь эту версию, выложи на сайт следующую (versionCode больше). Не переустанавливая:
      закрой приложение смахиванием, открой снова (или нажми «Проверить»): должен появиться баннер / кнопка «Скачать»
  [ ] «Скачать» открывает ссылку на APK, после установки поверх баннер пропадает
